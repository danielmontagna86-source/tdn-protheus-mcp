# Código de Conduta

Buscamos uma comunidade respeitosa, técnica e inclusiva. São bem-vindas contribuições construtivas, críticas fundamentadas e perguntas de boa-fé.

Não são aceitos assédio, discriminação, ataques pessoais, exposição de informações privadas, publicação de segredos ou conteúdo de terceiros sem autorização.

Para relatar uma violação, use os mecanismos de denúncia do GitHub ou o canal privado de segurança quando o relato contiver informação sensível. O mantenedor pode remover conteúdo, moderar interações ou restringir participação para preservar a comunidade.
