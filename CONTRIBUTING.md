# Como contribuir

Obrigado por ajudar a tornar o kit mais seguro e útil.

1. Abra uma issue antes de mudanças grandes.
2. Não envie conteúdo do TDN, caches, dados de clientes, logs com credenciais ou datasets em qualquer canal público.
3. Para mudanças de comportamento, escreva um teste que falhe primeiro e mantenha a suíte verde.
4. Execute `python -m unittest discover -s tests -p 'test_*.py' -v` e valide o ZIP antes de abrir o pull request.
5. Descreva objetivo, risco, testes executados e impacto de compatibilidade no PR.

Contribuições são submetidas sob Apache-2.0, salvo acordo escrito em contrário. Ao participar, siga o [Código de Conduta](CODE_OF_CONDUCT.md).
