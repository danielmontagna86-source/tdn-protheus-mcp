# Suporte

Use GitHub Issues para defeitos reproduzíveis e GitHub Discussions, quando habilitado, para dúvidas de uso. Não envie arquivos coletados do TDN, informação de clientes, credenciais ou dados pessoais.

O suporte cobre o código deste repositório e seus fluxos documentados. Não cobre autorização de uso de conteúdo TOTVS, configuração privada de ERPs ou suporte aos provedores de agentes.
