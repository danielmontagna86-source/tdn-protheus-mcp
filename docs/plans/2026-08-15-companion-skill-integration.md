# Companion Skill Integration Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use executing-plans to implement this plan task-by-task.

**Goal:** Document and regression-test the supported workflow in which the portable TDN collection skill creates a local snapshot that this MCP indexes and serves.

**Architecture:** Keep the Python MCP and the harness skill in separate public repositories. The MCP documentation links to the companion skill's installer, specifies the shared cache contract, and provides a safe hand-off flow. A repository test verifies that a schema-v1 portable-skill snapshot remains readable by the MCP.

**Tech Stack:** Markdown, Python 3.11+, `unittest`, JSON snapshot contract, GitHub-hosted companion skill.

---

### Task 1: Protect the shared snapshot contract

**Files:**
- Modify: `tests/test_snapshot_repository.py`

**Step 1: Add a portable-skill snapshot fixture**

Create a schema-v1 manifest and page record using the fields generated by `coletando-documentacao-tdn-protheus`.

**Step 2: Verify MCP read access**

Run:

```bash
python -m unittest tests.test_snapshot_repository -v
```

Expected: the repository returns the active portable-skill page and its citation URL.

**Step 3: Commit**

```bash
git add tests/test_snapshot_repository.py
git commit -m "test: cover companion skill snapshot contract"
```

### Task 2: Add user installation and hand-off documentation

**Files:**
- Create: `docs/companion-skill.md`
- Modify: `README.md`
- Modify: `docs/install.md`
- Modify: `docs/harness-compatibility.md`

**Step 1: Document boundaries**

State that the skill is installed separately and is responsible for optional online collection; the MCP stays local, cited, and read-only by default.

**Step 2: Document installation by harness**

Use the companion repository's `install.py` commands for Codex, Claude Code, Antigravity, and OpenRouter loaders. Include `--dry-run` before write operations.

**Step 3: Document the shared-cache flow**

Show the same `cache_root` in both tools, then skill snapshot/refresh, MCP `doctor`, MCP `index`, and MCP `serve`. Require an explicit reindex after collection.

**Step 4: Validate documentation and links**

Run `git diff --check` and verify every declared companion URL resolves to the public skill repository.

**Step 5: Commit**

```bash
git add docs README.md
git commit -m "docs: add companion skill installation guide"
```
